# Mobile app

The Chat screens in the Box mobile app, as a module the app registers alongside the others.

## Highlights

- A Chat tab in the Box mobile app with an unread badge, channels and direct messages
- Threads, reactions, mentions, attachments from the camera or files, and the agent's live activity
- In-app notifications for messages that arrive while you are elsewhere in the app

## Needs

- The Flutter SDK to build and test it
- Xcode or Android Studio for a device build
