# Notifications

One bell for everything that needs attention, merging chat mentions and messages with alerts, and delivering alerts straight into chat rooms. It is glue between Chat and Automation's Alerts powerup: remove it and both keep working on their own.

## Highlights

- A top-bar bell that merges chat mentions, messages and alerts into one list
- Web push and FCM device push delivery
- Chat transports so alerts post into a chat room or arrive as a direct message from the agent
- No tables of its own
