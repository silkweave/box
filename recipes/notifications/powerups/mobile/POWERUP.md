# Mobile app

Push notifications for the Box mobile app, as a module the app registers alongside the others.

## Highlights

- Push notifications on iOS and Android through Firebase Cloud Messaging
- Tapping a push opens the screen it is about, such as the chat room
- A Settings row that says whether this device can receive pushes, and why not

## Needs

- The Flutter SDK to build and test it
- A Firebase project with iOS and Android apps, and an APNs key from an Apple Developer account for iOS push
- Xcode or Android Studio for a device build
