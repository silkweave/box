# Mobile app

The Artifacts screens in the Box mobile app, as a module the app registers alongside the others.

## Highlights

- An Artifacts tab in the Box mobile app with the gallery, folder and tag filters and search
- Artifact details with owner, tags, views and the public link, and a full-screen viewer

## Needs

- The Flutter SDK to build and test it
- Xcode or Android Studio for a device build
