# Artifacts

A home for the pages, dashboards and web-app prototypes your team and its agents build: publish a static page or a whole built app, and everyone on the Box opens it at its own URL, comments on it in place, and can share a public copy when it needs to leave the building.

## Highlights

- Publish one HTML document or a built static tree from an agent, the gallery or a shell, at a stable slug
- Pages run with the full browser platform on the Box's own origin, with a small runtime for shared state
- Pinned comments with threaded replies on any page, from people in the page and from agents over MCP
- A gallery with folders, tags, kinds, owners and free-text search
- An import from the standalone artifacts host, keeping folders, saved page state and comments
