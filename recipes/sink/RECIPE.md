# Sink

An inbox for raw markdown notes such as chat exports, research dumps and post ideas, so nothing gets lost before it becomes tracked work. The team edits notes in the dashboard and hands each one to an agent to process.

## Highlights

- A queue of markdown notes kept as plain files in the Box
- Inline editor with autosave
- Create, read, save and delete notes from the dashboard or through agent tools
- One-step handoff of a note to an agent for processing
- No warehouse tables and no dependencies beyond core
