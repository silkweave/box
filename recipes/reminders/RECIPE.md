# Reminders

A small shared list of dated reminders that people and agents can both read and write. It is the smallest recipe that owns a table, and a clean starting point for a team's own customisations.

## Highlights

- Reminders with a title, a due date and time, and an optional description
- Open reminders listed first, soonest due at the top
- Mark done or reopen with one action
- Agent tools to list, create, complete and delete reminders
- One warehouse table, no dependencies beyond core
